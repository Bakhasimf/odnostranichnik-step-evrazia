# Степная Евразия — сайт научной программы

Одностраничный официальный сайт международной научной программы
**«История и культура народов Степной Евразии» (2026–2034)**.

## Структура

```
.
├── index.html               # вся разметка страницы
├── styles.css               # стили (light academic theme)
├── script.js                # табы, фильтры, активная навигация, reveal, форма
├── assets/
│   └── eurasia-map.svg      # декоративная карта Евразии для hero
└── README.md
```

## Запуск

Это статический сайт без сборки — достаточно открыть `index.html` в браузере.

Либо запустить локальный сервер (нужно для корректной загрузки `<object>` SVG-карты
в некоторых браузерах):

```bash
# Python 3
python -m http.server 8000

# или Node
npx serve .
```

Открыть `http://localhost:8000`.

## Кастомизация

### Цвета

Переменные в `:root` файла `styles.css`:

```css
--bg:         #f7f4ed;   /* основной фон — ivory */
--bg-alt:     #efeadd;   /* чередующиеся секции */
--ink:        #1c2330;   /* основной текст */
--accent:     #7d2f2f;   /* бордовый — заголовки, активные состояния */
--accent-2:   #0e2a47;   /* deep navy — кнопки */
--accent-soft:#b9893a;   /* золотой/охра — орнаменты */
```

### Типографика

- Заголовки: **Cormorant Garamond** (serif)
- Текст/UI: **Inter** (sans-serif)

Подключены через Google Fonts.

### Редактирование карточек

Все карточки — это повторяющиеся блоки прямо в `index.html`. Достаточно
скопировать `<article>` и поменять текст/теги/тип.

**Пример добавления публикации:**

```html
<article class="pub-card" data-type="Монография">
  <span class="pub-type">Монография</span>
  <h3>Название работы</h3>
  <p>Краткое описание...</p>
  <a href="#" class="pub-link">Подробнее →</a>
</article>
```

Атрибут `data-type` должен совпадать со значением в кнопке-фильтре
(`data-filter` в `.filter`).

**Добавить новый фильтр:**

```html
<button class="filter" data-filter="НовыйТип">Новый тип</button>
```

### Замена видео-превью

Сейчас превью — стилизованные цветные плашки (`data-pattern="p1..p6"`).
Для замены на реальные изображения:

```css
.video-thumb[data-pattern="p1"] {
  background: url("assets/video-1.jpg") center/cover;
}
```

Кнопка «Смотреть» ведет на `href="#"` — замените на ссылку на YouTube / Vimeo / локальное видео.

### Форма обратной связи

Сейчас форма валидирует поля и показывает сообщение-заглушку.
Для реальной отправки — замените логику в `script.js` (блок `form.addEventListener("submit", ...)`) на `fetch()` к вашему API или подключите Formspree / Getform.

## Адаптивность

- Desktop: ≥ 1100px — 3–4 колонки
- Tablet: 640–1100px — 2 колонки, горизонтальный скролл табов
- Mobile: ≤ 640px — 1 колонка, бургер-меню

## Доступность

- Семантическая разметка (`header`, `main`, `section`, `nav`, `footer`)
- ARIA-атрибуты на табах, бургер-меню, форме
- `prefers-reduced-motion` отключает анимации
- Контрастная типографика
